# 家长指南（Talking Kitty 会说话的猫咪）

本指南面向家长，介绍如何安装和使用"会说话的猫咪"，以及如何使用儿童锁功能。

## 1. 安装 APK

1. 在手机上下载 APK 文件（例如通过 GitHub Release 或直接拷贝文件 `Builds/TalkingKitty.apk`）。
2. 点击 APK 文件进行安装。系统可能提示"未知来源应用"，选择**允许**（仅对本次安装或对该来源允许）。
3. 安装完成后打开"会说话的猫咪"。
4. 本应用不需要联网，安装和使用全程离线。

> 需要Android 7.0（API 24）及以上版本。

## 2. 授予麦克风权限

1. 首次打开应用时，系统会弹出**麦克风权限**请求，请选择**允许**。
2. 如果当时点了"拒绝"，可以手动开启：
   - 打开系统 **设置 → 应用 → 会说话的猫咪 → 权限 → 麦克风**，选择"允许"。
3. 这是应用请求的**唯一**权限。录音只在本机临时保存，回放后即丢弃，不会上传任何数据。

## 3. 设置家长 PIN 码

1. 解锁进入家长界面时（见下文"解锁手势"），首次会要求**设置 4 位 PIN 码**。
2. 输入两次相同的 4 位数字即设置成功。
3. 请记住这个 PIN。如果忘记 PIN，只能通过**清除应用数据**（设置 → 应用 → 会说话的猫咪 → 存储 → 清除数据）来重置。

## 4. 开启儿童锁

进入家长界面后，打开**儿童锁**开关。开启后：

- 应用内的返回键、退出/设置/分享按钮都会被屏蔽。
- 应用进入全屏沉浸模式，孩子无法误触退出。

## 5. 家长解锁手势

孩子玩的时候应用是锁定的；家长需要进入家长界面时，使用以下任一手势：

- **角落长按 3 秒**：按住屏幕任意一个角约 3 秒；
- **顶部连点 5 次**：快速点击屏幕顶部中间区域 5 次。

然后输入 4 位 PIN 码即可进入家长界面。在家长界面里可以关闭儿童锁、调整音调、退出应用。

## 6. 已知限制：Home 键

Android 系统的**主页键（Home）/ 最近任务键**属于系统级操作，应用无法完全屏蔽，孩子仍可能通过它们离开应用。这是 Android 平台的已知限制。

## 7. 可选加固：系统"屏幕固定"

如果需要更强的保护，可以配合 Android 系统自带的**屏幕固定（Screen Pinning）**功能：

1. 打开系统 **设置 → 安全（或生物识别与安全）→ 屏幕固定**，开启该功能（不同手机路径略有差异，可在设置里搜索"屏幕固定"）。
2. 打开"会说话的猫咪"，按最近任务键，点击应用卡片上的**固定（图钉）**图标。
3. 固定后，Home 键和最近任务都被禁用，孩子无法退出应用。
4. 家长要退出时，同时按住**返回键 + 最近任务键**（部分机型为返回 + Home），输入锁屏密码即可解除固定。

## 8. 常见问题

- **没有声音 / 猫咪不回应**：检查麦克风权限是否已授予（见第 2 节）；检查手机媒体音量。
- **忘记 PIN**：清除应用数据后重新设置（见第 3 节）。
- **误触发解锁界面**：正常游戏中角落/顶部手势不容易触发；若被孩子误触，输入 PIN 前直接按返回键即可关闭。
